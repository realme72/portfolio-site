# Gaurav Bharti: portfolio

Personal portfolio site: an interactive doodle desk, project bento grid, and an animated room scene with a day/night toggle.

Plain HTML/CSS/JS, no build step.

```sh
python3 -m http.server 5173   # then open http://localhost:5173
```

- `index.html`: home (desk, work, contact)
- `about.html`: about page with the animated room scene
- `desk.js`: draggable doodle desk + BYTE speech bubble
- `scene.js`: room illustration, day/night state machine
- `script.js`: shared config (email, links, career start date), badges, emotes
- `style.css`: dark IDE theme
